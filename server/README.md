# Overman API

Go API и PostgreSQL для аккаунтов, дневника, однократных наград, дружбы, добровольных разрешений и совместных серий сна.

Запуск и локальная настройка описаны в корневом README. Код API: `cmd/overman` и `internal/api`; миграции: `db/migrations`.

- Локальный адрес: `http://127.0.0.1:3902` при запуске через `scripts/local-api.mjs`.
- Сессии передаются Bearer-токеном; состояние пользователя и награды сохраняются транзакционно.
- Повторная операция не должна повторно начислять награду.
- Серверные проверки используют отдельные вымышленные аккаунты и отдельную тестовую базу.
- Конфигурация соединения и пароли создаются локально и в репозиторий не включаются.

```sh
go test ./...
go vet ./...
```

Прямой запуск с установленным Go: `go run ./cmd/overman -config PATH_TO_LOCAL_CONFIG`. Для публичного размещения используйте `../deploy/vps/`.
